# Eola Spine & Posture

One-page website for a chiropractic clinic in Downtown Orlando, FL.

**Live site:** https://riderrouge13-commits.github.io/eola-spine-posture/

## What's here

- `index.html`: the whole site (styles and scripts included)
- `img/`: photos (Unsplash, credited in the footer), the built-in street map (© OpenStreetMap contributors) and the social share image

## Before launch

- Replace the sample clinic details (name, address, phone, hours, insurers, rating) in the page **and** in the JSON-LD schema at the top of `index.html`.
- Connect the intake form to a HIPAA-compliant provider that signs a BAA (IntakeQ, Jotform HIPAA, or your EHR). It is front-end only right now.
- Optional: add a Google Maps Embed API key (see the comment above the map).
- Service links currently jump to sections on this page. Swap them for the localized sub-pages once they exist.

## Updating the site

Edit `index.html`, commit, and push to `main`. GitHub Pages republishes in about a minute.
